# FIBARO / Yubii Cloud 0.1.0

Initial release of an unofficial Home Assistant integration for accessing a
Fibaro / Yubii hub through the vendor cloud. Intended for installations such as
a cabin where Home Assistant cannot reach the hub locally.

Requires **Home Assistant 2026.11.0 or later**. Earlier versions are not supported.

- Cloud login, hub selection, local hub authentication and main-device selection.
- Sensors, binary sensors, switches, lights, thermostats and covers where the
  hub reports supported capabilities.
- Main-device grouping, battery consolidation and Fibaro device-name updates.
- Automatic session renewal with bounded retries and manual reauthentication
  as a fallback. Device commands are never replayed automatically.
- Privacy-limited diagnostics with masked configuration values.
- FIBARO / Yubii display name and cloud icons for light and dark themes.

Install through Marketplace **Add from link** using
`https://github.com/bkflatekvaal/ha-fibaro-cloud`, then follow the setup instructions
in the README. This release does not imply inclusion in the default catalog.

Only HC3 Lite switch and thermostat control have been confirmed in live use.
Other models and light/cover control have not been verified on real hardware.
MFA/CAPTCHA are not automated. Changes to undocumented vendor cloud endpoints
can interrupt access.

This is a personal hobby project with limited maintenance and support time.
Use at your own risk. It is not affiliated with Fibaro, Yubii, Nice or Home
Assistant. Protect your HA configuration and backups, which contain credentials.
